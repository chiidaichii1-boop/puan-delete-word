## The pick

**moist**

One word, and the joke lands the moment it is gone: "moist" is famously
the word people love to hate hearing, purely because of how it sounds.
Erase it and no other single word quite says "slightly wet in the worst
possible way" — a small, funny gap in the language.

## How it works

`main.py` (Python 3, standard library only) writes the single word to
`entry.txt` in the output directory given by `MAKEFUN_OUTPUT_DIR`
(`/output` by default). It reads no input data and writes nothing else.
